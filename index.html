    Load a Java Edition world

    Pick your world folder, a .zip of it, or individual region files. The world is read inside this browser tab and never uploaded anywhere.

    You can also drop a folder or .zip anywhere on the map. Works with Minecraft 1.13 and newer. Bedrock Edition worlds use a different format and can't be read.

    Where to find your world
    Windows
    %APPDATA%\.minecraft\saves\<world>
    macOS
    ~/Library/Application Support/minecraft/saves/<world>
    Linux
    ~/.minecraft/saves/<world>
    Server
    world/ next to the server jar. Paper and Spigot keep the Nether and End in world_nether/ and world_the_end/, so zip the server folder to map all three.
